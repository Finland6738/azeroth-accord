# Third-party material and licences

The addon is GPL-3.0 ([LICENSE](../LICENSE)). This page records where every font, picture and library that ships in the
package comes from and under which licence. It is the single place to update when one is added: `tools/check_addon.py`
fails when a file of `AzerothAccord/Media/` is not named here or a font family has no licence text.

The files of `Media/` are made by `tools/make_icons.py` (the icons), `tools/make_media.py` and `tools/make_fonts.py`, the
last two adapted from the sibling addon Finland
Dragon Credit Points (FDCP, same owner, GPL-3.0; [ADR 0021](adr/0021-interface-follows-the-ecosystem-style-of-fdcp.md)).

## Fonts (`AzerothAccord/Media/Fonts/`)

| Family | Files | Licence | Notes |
|---|---|---|---|
| **Outfit** (The Outfit Project Authors) | `Outfit-Regular.ttf`, `Outfit-Medium.ttf`, `Outfit-SemiBold.ttf` | SIL Open Font License 1.1, text in `Outfit-OFL.txt` | Static instances cut from the variable font and reduced to the Latin subset by FDCP's `tools/make_fonts.py`. No Reserved Font Name. |
| **JetBrains Mono** (The JetBrains Mono Project Authors) | `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Medium.ttf` | SIL Open Font License 1.1, text in `JetBrainsMono-OFL.txt` | Same treatment. No Reserved Font Name. |
| **Orbitron** (Matt McInerney, The League of Moveable Type) | `Orbitron-Bold.ttf`, `Orbitron-OFL.txt` | SIL Open Font License 1.1, text in `Orbitron-OFL.txt` | Declares the Reserved Font Name "Orbitron", so the file ships **whole and unmodified**. Used for window titles, in capitals. |

Accord's `tools/make_fonts.py` copies these files **byte for byte** from FDCP's `Media/Fonts/` (the output of FDCP's own
tool, which downloads and cuts them), so Accord's fonts are identical to FDCP's and the tool needs no network.

The OFL allows bundling the fonts in software under any licence provided the fonts are not sold on their own, the licence
text accompanies them and a modified version does not reuse a Reserved Font Name. The community site's logo font
(Atomed) has no licence that allows redistribution and is **not** included.

## Icons (`Media/symbols.tga`)

| What | |
|---|---|
| Source | **Material Symbols Rounded**, by Google: the official repository [google/material-design-icons](https://github.com/google/material-design-icons), commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7` (2026-10-23), file `variablefont/MaterialSymbolsRounded[FILL,GRAD,opsz,wght].ttf` |
| Licence | **Apache License 2.0**, text in `Media/symbols-LICENSE.txt` (the repository's `LICENSE`); compatible with GPL-3.0 |
| What ships | `symbols.tga`: only the glyphs the addon uses, 49 outlined and 24 filled |
| Changes | `tools/make_icons.py` draws each glyph (weight 400, grade 0, optical size 24; fill 0 or 1) as a white picture and places it in one 512 × 512 atlas of 48 px cells; the theme tints them at run time |

The font itself is **not** shipped and is not in the repository: the tool downloads it into `tools/.cache/` (git-ignored)
and checks its SHA-256. The names and the order of the cells are mirrored in `UI/Assets.lua`, which
`tools/check_addon.py` compares. The icons of the game (classes, items, recipes) are the client's own and are only
used by name at run time.

## The logos

- **Azeroth Accord logo** (`Media/logo_256.tga`, `Media/logo_64.tga`): made from `assets/logo-source.webp`, the addon's own
  logo, supplied by the repository owner. It is the icon of the AddOn Compartment and of the window. The GPL-3.0 of the code
  does not by itself grant a right to use the logo for another purpose.
- **NEBULA logos** (`Media/nebula_dark_256.tga`, `Media/nebula_light_256.tga`): made from `assets/nebula-logo-dark.png` and
  `assets/nebula-logo-light.png`, the logos of the Italian guild NEBULA, **used with the guild's permission** for the credits
  (dark one on dark themes, light one on the light theme). They are not covered by the GPL-3.0 grant for any other use.

## The design previews

The pictures of `docs/specs/mockups/` (the wiki and README images) are drawings made by `tools/make_mockups.py` in a local browser: they show the glyphs of the fonts above (Outfit, JetBrains Mono and Orbitron, read from `AzerothAccord/Media/Fonts/`, SIL OFL 1.1), the addon's logo and the NEBULA logos (same permission as above). They contain no Blizzard art; the game's guild window in them is drawn in the theme with generic line icons. The comparison sheet also shows previews of Finland Dragon Credit Points (same owner, GPL-3.0).

## Game art

No Blizzard artwork is copied into the repository. The addon uses the game's own textures and fonts only by name at run
time (for example the guild-window tab icon), never as files.

## Libraries (`AzerothAccord/Libs/`, fetched at packaging time)

Ace3 (Release-r1403), LibDataBroker-1.1 (v1.1.4) and LibDBIcon-1.0 (v8.0.4) are embedded by the packager from the
versions pinned in `.pkgmeta`; each is a whole repository at a tag and keeps its own licence file inside its folder.
