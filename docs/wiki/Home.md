# Azeroth Accord

*Italiano: [[Italiano|Home-it]]*

![Azeroth Accord logo](../../assets/logo-source.webp)

**A richer guild window for World of Warcraft: Forever.** Azeroth Accord adds an **Accord** tab to the game's guild window: an extended roster with professions and recipes, the characters of each account, contacts, likes, a social index and the guild bank with requests.

> **Status: test version, in-game checks open.** The first release is `v0.8.0` (2026-11-25): the Accord tab, the standalone window, the roster, professions, likes, the guild bank, the settings, the officer tools and the Italian interface. It has been tested offline only; nobody has checked it in the game yet. Download it from the repository's *Releases* page ([[Installation|Installation]]). `v0.9.0` (2026-11-25) added the [[Action Center|Action-Center]] with notices, quiet hours and a summary at login, the guild's [[group finder|Groups]] and the [[Guild addons|Guild-Addons]] table. `v0.10.0` (2026-11-26) added the [[season roster|Season-Roster]], [[events|Events]] on the game calendar with bench and composition and PvP and world rallies, the import of [[Raid-Helper events|Raid-Helper]] and the [[availability map|Availability]], with the in-game checks pending. `v0.11.0`, the next release, adds the [[guild handbook|Guild-Handbook]] with its loot page and the [[Raid view|Raid-and-Loot-Addons]], with the in-game checks pending too. Each later milestone is released as `v0.<milestone>.0`; `v1.0.0` comes when every planned milestone, up to M16, is done. The pictures in this manual are design previews, not screenshots.

![The Accord tab in the guild window: the roster of the guild with professions, likes and who runs the addon](../specs/mockups/previews/accord-tab-roster.webp)

*Design previews, not screenshots: drawn from the addon's own layout and texts with invented characters and items, because the addon has not been run in the game yet ([all previews](https://github.com/Finland6738/azeroth-accord/blob/main/docs/specs/mockups/previews/README.md)).*
